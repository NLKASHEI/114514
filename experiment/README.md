# experiment · 道渊 MVU 注入特化

> 分支：`experiment` · 版本：1.1.0
> 实验性：不改世界书、不改 MVU、不改 ZOD。禁用脚本 = 完全回滚。

## 它做什么

挂在**酒馆助手**上的局部脚本，只在「请求组装」这一步动手：

1. **投影**：把 `<status_current_variables>` 里的整棵 `stat_data` 换成裁剪版（YAML）。
2. **在场裁剪**：道侣 / 人物 / 灵宠 / 玉简，只给「最近消息或当前地点里出现过」的人全文，其余压成摘要并标 `在场: false`。
   已经出过场的人会**延续 `presenceHold` 轮**保持全文，避免"刚做完就失忆"。
3. **变更日志**：追加 `<mvu变量上一轮次修改日志>`——时间推进/回退校验 + 上一轮净变化清单。
4. **时间守卫**（可选，默认关）：越界或无法解析的时间，在写入前回滚到上一楼合法值。

思路对照《命定之诗与黄昏之歌》的 `destinyVisibleState` / `destinyParseTime` / `mvu变量修改日志`。

## 实测（v5.4.2 真实存档最后一楼，11 位道侣 / 4 位人物）

| 项目 | 字数 |
| --- | --- |
| 原始 `stat_data` | 6,831 |
| 投影（v1.0，含在场裁剪） | **3,995（-2,836，-41.5%）** |
| 变更日志 | 332 |
| 净省 | ≈ 2,500 字/次请求 |

投影片段：

```yaml
道侣:
  苏沐雪:
    性别: 女
    种族: 人族
    境界: 合体后期（DC:151）
    亲密: 100
    状态: 正常
    修为: 60
    在场: false          # ← 未在场，只留摘要
  青练:                  # ← 在最近对话/地点里出现，全文保留
    性别: 女
    境界: 妖圣·大乘
    外观: …（24 字）
    心声: …（24 字）
```

日志片段：

```
上轮净变化已生效，勿重复执行；此处仅记录变动信息。
时间：推进23小时45分钟。
世界：当前地点更新；遭遇冷却-1、移除「青丘女官传讯」、新增「南离血煞异动」。
主角：衣着、神念更新；灵力-2、神识-2、道心+2。
```

时间回退时：

```
⚠ /世界/当前时间 回退：…14点30分 → …14点15分（-15分钟）。
下次更新必须把时间修正为不早于「…14点30分」，并按剧情补足应经过的时长。
```

## 安装

酒馆助手 → 局部脚本 → 新增：

```js
import 'https://cdn.jsdelivr.net/gh/NLKASHEI/114514@experiment/experiment/道渊MVU注入特化.js'
```

依赖：MagVarUpdate 已加载；酒馆助手支持 `CHAT_COMPLETION_SETTINGS_READY`。

## 配置

控制台随时改：

```js
DaoYuanEXPR.set({ presence: false })       // 关掉在场裁剪
DaoYuanEXPR.set({ timeFix: true })         // 打开时间回滚（实验性）
```

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `maxText` | 28 | 长文本默认保留字数 |
| `yujianKeep` | 3 | 玉简保留最近几条（在场的） |
| `log` | true | 是否追加变更日志 |
| `logMax` | 24 | 单组最多展示多少条差异 |
| `presence` | true | 是否按在场裁剪 |
| `presenceFloors` | 4 | 往前看几楼判断在场 |
| `presenceHold` | 2 | 出场后继续保持全文几轮 |
| `timeFix` | false | 时间越界时是否回滚 |

字段规则：`DROP_FIELDS` = 仙姿 / 群芳谱 / 引言（不进提示词，状态栏照旧显示）；
`FIELD_LIMIT` = 外观 24 / 心声 24 / 背景 16 / 描述 24 / 性格 10 …

## 它不动什么

- `stat_data` 本身不动（`timeFix` 打开时除外），状态栏/悬浮窗/前端照旧。
- MVU 的解析、应用、ZOD 校验照旧。
- 世界书一条不改；变量列表条目即使关掉，也会兜底插一条 system 消息。

## 已知限制

- 在场判断用「最近 4 楼文本 + 当前地点」的**字面匹配**，同名/昵称可能漏判。觉得谁被压得太狠，把 `presenceFloors` 调大。
- `timeFix` 只回滚时点，不会替你补"应该过了多久"——补时长仍是剧情的事。
- 日志本身占 300 字左右，净省约 2,500 字/次。
