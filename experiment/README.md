# experiment · 道渊 MVU 注入特化

> 分支：`experiment` · 版本：0.1.0
> 状态：实验性，默认不改任何世界书、不改 MVU、不改 ZOD。

## 这是什么

一份挂在**酒馆助手**上的局部脚本。它不改 MVU 的解析与写入，只在**请求组装**这一步做两件事：

1. 把注入给模型的 `<status_current_variables>…</status_current_variables>` 里的整棵 `stat_data`，换成裁剪过的「投影」（YAML）。
2. 在同一位置追加一段 `<mvu变量上一轮次修改日志>`：时间推进/回退校验 + 上一轮的净变化清单。

思路对照《命定之诗与黄昏之歌》的 `destinyVisibleState` / `destinyParseTime` / `mvu变量修改日志`——同样是提示词侧计算，不做代码结算。

## 它不动什么

- `stat_data` 本身不动，状态栏、悬浮窗、前端读到的仍是完整数据。
- MVU 的解析、应用、ZOD 校验全部照旧。
- 世界书一条不改。变量列表条目（`<status_current_variables>`）即使关掉，脚本也会兜底插一条 system 消息。

## 实测（用 v5.4.2 真实存档的最后一楼状态）

| | 字数 |
| --- | --- |
| 原始 `stat_data` | 6,831 |
| 投影 | 5,289（-1,542，-22.6%） |
| 变更日志 | 338 |

日志样例：

```
上轮净变化已生效，勿重复执行；此处仅记录变动信息。
时间：推进23小时45分钟。
世界：当前地点更新；遭遇冷却-1、移除「青丘女官传讯」、新增「南离血煞异动」。
主角：衣着、神念更新；灵力-2、神识-2、道心+2。
```

时间回退时：

```
⚠ /世界/当前时间 回退：元会历·3728年·5月15日·14点30分 → 元会历·3728年·5月15日·14点15分（-15分钟）。
下次更新必须把时间修正为不早于「元会历·3728年·5月15日·14点30分」，并按剧情补足应经过的时长。
```

## 安装

酒馆助手 → 角色卡局部脚本 → 新增 → 内容：

```js
import 'https://cdn.jsdelivr.net/gh/NLKASHEI/114514@experiment/experiment/道渊MVU注入特化.js'
```

（也可以用 `testingcf.jsdelivr.net` 前缀，国内更快。）

依赖：MagVarUpdate 已加载、酒馆助手版本支持 `CHAT_COMPLETION_SETTINGS_READY` 事件。

## 配置

脚本顶部的 `CFG`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `maxText` | 28 | 长文本保留字数 |
| `yujianKeep` | 3 | 玉简每个好友保留最近几条 |
| `log` | true | 是否追加变更日志 |
| `logMax` | 24 | 单组最多展示多少条差异 |
| `debug` | true | 控制台输出投影/日志体积 |

字段级规则：`DROP_FIELDS`（仙姿、群芳谱、引言——状态栏仍显示，只是不进提示词）、`FIELD_LIMIT`（外观 24 / 心声 24 / 背景 16 / 描述 24 …）。

## 回滚

禁用或删除这个脚本即可，行为立刻回到原样。

## 已知限制

- 道侣/人物**全量**注入，只压文本，不按在场裁剪（v0.2 计划）。
- 时间只**报错不修改**：脚本没有回写变量，避免和叙事打架（`timeFix` 开关预留在 roadmap）。
- 日志本身占 300 字上下，净省约 1.2k 字/次请求。

## 路线

- v0.2：在场感知投影（道侣/NPC 只有出现在最近消息或当前地点时才全文注入）。
- v0.3：时间回写开关（可选修复，不默认开启）。
- v0.4：与主脚本 `道渊配置小助手` 面板打通（开关、体积统计）。
