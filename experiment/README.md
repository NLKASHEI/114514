# experiment · 道渊 MVU 注入特化

> 分支：`experiment` · 版本：1.6.0
> 实验性：不改世界书、不改 MVU、不改 ZOD。禁用脚本 = 完全回滚。

## 它做什么

挂在**酒馆助手**上的局部脚本，只在「请求组装」这一步动手：

1. **投影**：把 `<status_current_variables>` 里的整棵 `stat_data` 换成裁剪版（YAML）。
2. **在场裁剪**：道侣 / 人物 / 灵宠 / 玉简，只给「最近消息或当前地点里出现过」的人全文，其余压成摘要并标 `在场: false`。
   已经出过场的人会**延续 `presenceHold` 轮**保持全文，避免"刚做完就失忆"。
3. **变更日志**：追加 `<mvu变量上一轮次修改日志>`——时间推进/回退校验 + **上一次已落地**的净变化（不拿还在飞的请求做对比）。
4. **时间守卫**（可选，默认关）：越界或无法解析的时间，在写入前回滚到上一楼合法值。

思路对照《命定之诗与黄昏之歌》的 `destinyVisibleState` / `destinyParseTime` / `mvu变量修改日志`。

## 实测（v5.4.2 真实存档最后一楼，11 位道侣 / 4 位人物）

| 项目 | 字数 |
| --- | --- |
| 原始 `stat_data` | 6,831 |
| 投影（v1.0，含在场裁剪） | **3,995（-2,836，-41.5%）** |
| 变更日志 | 332 |
| 净省 | ≈ 2,500 字/次请求 |

投影片段：

```yaml
道侣:
  苏沐雪:
    性别: 女
    种族: 人族
    境界: 合体后期（DC:151）
    亲密: 100
    状态: 正常
    修为: 60
    在场: false          # ← 未在场，只留摘要
  青练:                  # ← 在最近对话/地点里出现，全文保留
    性别: 女
    境界: 妖圣·大乘
    外观: …（24 字）
    心声: …（24 字）
```

日志片段：

```
上轮净变化已生效，勿重复执行；此处仅记录变动信息。
时间：推进23小时45分钟。
世界：当前地点更新；遭遇冷却-1、移除「青丘女官传讯」、新增「南离血煞异动」。

```

时间回退时：

```

下次更新必须把时间修正为不早于「…14点30分」，并按剧情补足应经过的时长。
```

## 配置

控制台随时改：

```js
DaoYuanEXPR.set({ presence: false })       // 关掉在场裁剪
DaoYuanEXPR.set({ timeFix: true })         // 打开时间回滚（实验性）
```

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `maxText` | 28 | 长文本默认保留字数 |
| `yujianKeep` | 3 | 玉简保留最近几条（在场的） |
| `log` | true | 是否追加变更日志 |
| `logMax` | 24 | 单组最多展示多少条差异 |
| `presence` | true | 是否按在场裁剪 |
| `presenceFloors` | 4 | 往前看几楼判断在场 |
| `presenceHold` | 2 | 出场后继续保持全文几轮 |
| `timeFix` | false | 时间越界时是否回滚 |
| `debugPanel` | true | 左下角调试面板 |

字段规则：`DROP_FIELDS` = 仙姿 / 群芳谱 / 引言（不进提示词，状态栏照旧显示）；
`FIELD_LIMIT` = 外观 24 / 心声 24 / 背景 16 / 描述 24 / 性格 10 …

## 调试面板

装好后**左下角**会出现一个小按钮「道渊EXPR」，点开是四块内容：

| 区块 | 内容 |
| --- | --- |
| 概览 | 字数账、在场名单、时间解析结果、请求/输出状态 |
| 注入给模型的变量块 | 实际替换进去的投影 + 日志全文 |
| 请求体 | **真正发给 API 的全部消息**（含系统提示、世界书、历史），最多留 4 次 |
| 主模型输出（正文） | 最近一条 AI 回复的正文 |
| 额外模型输出（变量更新块） | 额外模型返回的 `<UpdateVariable>` 原文 + JSONPatch 解析结果 + MVU 解析出的命令 + **应用前/后状态摘要** + 实际生效的变更 |

按钮：

- **导出全部**：下载 `道渊EXPR-时间戳.txt`（浏览器拦截下载时自动退化成全屏文本框，Ctrl+A / Ctrl+C 手动复制）
- **导出请求 / 导出输出 / 导出更新块**：单独导出
- **文本框**：直接打开全屏文本框，不依赖剪贴板
- 复制全部 / 刷新

概览里的诊断行：

- `对比：# 173 → # 175，净变化 N 组` —— 0 组说明这两楼状态完全一样
- `上一楼 / 当前` 两行摘要（时间、修为、生命、冷却、地点），一眼看出差在哪
- `上次落地：# 更新于 20:06:05（第 3 次额外请求，起于 20:03:58）` —— 额外模型重试次数、延迟一目了然
- `⚠ 额外模型已请求 N 次，尚未落地` —— 说明变量还停在上一轮
- `最近请求` 列表：最多 4 条，每条标了 **主模型 / 额外模型** 和 **投影(YAML) / 原始(JSON) / 未找到状态块**

如果列表里主模型那条显示「原始(JSON)」，说明主请求没走到改写钩子（比如不是 chat completion 后端），需要反馈。

控制台接口：

```js
DaoYuanEXPR.stats()     // { raw, projection, log, saved }
DaoYuanEXPR.preview()   // 打印本轮投影与日志
DaoYuanEXPR.who()       // 当前被判定为"在场"的名字
DaoYuanEXPR.dump()      // 返回面板里的完整文本（可复制）
DaoYuanEXPR.panel()     // 打开面板
```

控制台每回合会打：`[道渊EXPR] 投影 3995 字（原始 6831 字，省 2836 字），日志 332 字`

```bash

```

## 它不动什么

- `stat_data` 本身不动（`timeFix` 打开时除外），状态栏/悬浮窗/前端照旧。
- MVU 的解析、应用、ZOD 校验照旧。
- 世界书一条不改；变量列表条目即使关掉，也会兜底插一条 system 消息。

## 已知限制

- 在场判断用「最近 4 楼文本 + 当前地点」的**字面匹配**，同名/昵称可能漏判。觉得谁被压得太狠，把 `presenceFloors` 调大。
- `timeFix` 只回滚时点，不会替你补"应该过了多久"——补时长仍是剧情的事。
- 日志本身占 300 字左右，净省约 2,500 字/次。
